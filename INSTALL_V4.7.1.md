# Futures Academy v4.7.1 — Progressive Vault Emblems

This is a cumulative project package built from v4.7 Core RPG.

## Install
1. Back up your current project folder.
2. Extract this ZIP.
3. Copy everything inside the extracted folder into your project root.
4. Choose Merge and Replace.
5. Commit: `Add progressive Account Vault emblems`
6. Push and wait for Vercel.

No Supabase SQL is required.
