# Futures Academy v4.7 Core RPG

## Install
1. Back up your current repository.
2. Extract this ZIP.
3. Copy the contents of the extracted project folder into your existing project root.
4. Choose Merge and Replace.
5. Keep your existing Vercel environment variables.
6. Commit and push with: `Launch v4.7 Core RPG`.

No new Supabase SQL is required.

## Verify
- Academy Path shows 20 trader classes.
- Career uses animated symbolic emblems instead of Roman numerals.
- Handbook uses the same deep-black page background as Command Center.
- Achievement notifications dismiss automatically after 5.2 seconds.
