# Futures Academy v4 Visual System

## Core colors

- Electric blue: navigation, actions, evaluation progress
- Cyan: information, skill progression, active states
- Violet: RPG, classes, rank emblems, premium progression
- Gold: rewards, Legendary items, marketplace prestige
- Green: success, eligibility, account safety
- Red: loss, failure, locked-risk warnings
