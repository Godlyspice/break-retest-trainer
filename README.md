# Futures Academy v2.0 Foundation

This is Build 1 of the professional architecture and evaluation rewrite.

It upgrades the existing application rather than replacing the simulator.

## Major changes

- Modular evaluation account system
- Professional prop-style evaluation selection
- Tradeify-inspired `Start with $10K` call-to-action
- Account rules shown before starting
- Secure Supabase evaluation creation
- One active evaluation per user
- Guest Starter evaluation fallback
- Empty leaderboards until real users qualify
- Longer career progression up to 1,000,000 XP
- Reputation requirements up to 200,000
- Fixed nullable Supabase client calls in the supplied component

See `INSTALL.md` for deployment instructions.
