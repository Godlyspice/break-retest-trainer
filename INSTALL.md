# Futures Academy v4.6 — Learning, Trophies & Vault Expansion

This is a cumulative drag-and-drop package based on v4.5.

## Included

- All previous v4.5 responsive fixes
- Darker Handbook matching the main interface
- Expandable in-depth Handbook lessons
- Practical examples for every Handbook topic
- Practice buttons retained
- 30 achievements and trophies
- Achievement categories, rarities, and reward labels
- Animated achievement popup when a new milestone is reached
- Upgraded Trophy Room
- Animated neon Account Vault emblems
- Custom account-specific icon colors
- Locked-account emblem treatment

## Install

1. Extract the ZIP.
2. Drag all folders into your project root.
3. Choose Merge and Replace.
4. Commit and push:

`Expand learning trophies and account vault`

No new Supabase migration is required.
